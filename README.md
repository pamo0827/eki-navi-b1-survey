# 新宿駅 地下1階 看板の記録と経路

新宿駅の地下1階（JR の改札の中）で、案内板の位置・向き・写真を記録し、改札の中の道筋をなぞって最短経路を見るページです。サーバーなしで動く静的なページで、GitHub Actions で GitHub Pages に出します（`main` に push すると公開）。検索には載らないようにしています（`noindex`、`robots.txt`）。

## 使い方（index.html）

上の切り替えで3つの使い方を選びます。

- **看板**: 看板のボタンで印を出し、板をドラッグして位置、つまみを回して表の向きを決める → 表（と、あれば裏）の写真と大きさ → 記録 → ZIP で保存。ZIP には `signs.json`（eki-navi の `server/station_data/signs.json` と同じ形）と `photos/<imageName>.jpg` が入る。記録はページを開くたびに空になる
- **道**: 何もない所を押すと点を足し、選んでいる点とつなぐ。点を押すと選ぶ。選んでいるときに別の点を押すと、その2点の線をつなぐ／外す。点はドラッグで動かす。道はこの端末に残り、保存のボタンで JSON に書き出せる（`nodes` の `x`・`z` は共通座標の m、`edges` は点の id の組）。左下のボタンで JSON を読み込める
- **経路**: 点を2つ押すと、道の上の最短経路と距離を出す

座標は eki-navi の共通座標（x = 東、z = 北、メートル。原点 北緯 35.69・東経 139.70）です。

## 下絵（data/）

- `config.json`: 下絵の画像と、画像のピクセル → 共通座標の変換（`transform`。x = a·u + b·v + c、z = d·u + e·v + f）
- `base.png`: 下絵。今は国交省の「新宿駅周辺屋内地図オープンデータ」から作った画像
- `reference.png`: 位置合わせの基準（国交省のデータから作った画像。変換は `reference.transform`）
- `signs.json`: eki-navi にもうある地下1階の看板（地図に薄く出す）
- `network.json`: 道の初期値（端末に道がないときに読む）

### JR の構内図を下絵にする（各端末で読み込む）

地図の画面の右上のボタンで、JR 東日本の新宿駅構内図（地下1階、改札の中）のスクリーンショットを選ぶと、その端末の下絵が JR の構内図になります。画像はその端末（IndexedDB）に残るだけで、どこにも送りません。リポジトリに入っているのは位置合わせの数字（`config.json` の `jr`）だけです。

- 位置合わせは `config.json` の `jr` に画像ごとに入っています。読み込んだ画像と縦横の比が同じ（0.5% まで）ものを自動で使い、大きさが違えば縮尺だけ直します
  - 1680×1458（東西自由通路を含む）: calibrate.html の6組＋目印13か所。ずれ 平均 1.6 m・最大 3.5 m
  - 1220×1078（改札の中だけ）: 目印13か所。ずれ 平均 1.4 m・最大 3.0 m
  - 目印はエレベーター H・J・L・N・F、各番線への階段とエスカレーター、小田急線のりば、中央西改札の精算所。南東側（15・16番線〜小田急線のりば）がいちばんずれます
- JR の構内図は北が左を向いていますが、変換に回転が入っているので、看板の位置と向き（`azimuthDeg`）は北を基準にした値で記録します
- 別の切り取り方のスクリーンショットを使うときは、calibrate.html で位置合わせを作り、`jr` に足します

### 下絵そのものを差し替える

1. `calibrate.html` を開き、右上のボタンで JR の構内図の画像を開く（画像はどこにも送らない）
2. 上の「基準」で目印（改札の端、柱、通路の角など）を押し、下の「下絵」で同じ場所を押す。これを 6〜8 組、画像全体に散らして行う
3. ずれ（m）を見て、大きい組は消してやり直す。「基準を下絵に重ねる」で重なり具合を確かめる
4. 「config.json を保存」で保存し、`data/config.json` を置き換える。JR の構内図を `data/base.png`（JPEG なら `base.jpg`）として置く

JR 東日本の構内図は JR 東日本の著作物です。使ってよいか確かめてから置いてください。

## 手元で開く

```
python3 -m http.server 8000
```

http://localhost:8000/ を開きます（`file://` では `data/` を読めません）。
